# カードシリーズ追加ガイド

## 関連ファイル

- カード定義: `src/features/soroban/cardCatalog.ts`
- カード画像: `src/assets/cards/`
- ガチャ画面: `src/features/soroban/views/GachaPage.tsx`
- カードずかん: `src/features/soroban/views/CardBookPage.tsx`
- 保存状態: `src/features/soroban/state.ts`

カードはショップ商品ではない。`cardCatalog.ts` で定義し、所持状態は既存の `learning-arcade:soroban-state` 内にある `registerProgress.purchasedItemIds` にカードIDを保存して管理する。

## カード定義の形

`CardItem` は次の形。

```ts
{
  id: string;
  name: string;
  image: string;
  description: string;
  addedOn: string;
  gachaId: CardGachaId;
  orientation?: "portrait" | "landscape";
}
```

シリーズ追加時にやること:

1. 画像 import を追加する。
2. `CardGachaId` に新しい文字列リテラルを追加する。
3. `CARD_GACHA_DEFINITIONS` にシリーズ定義を追加する。
4. `KEIMARUKUN_CARDS` にカード定義を追加する。

`GachaPage.tsx` は `CARD_GACHA_DEFINITIONS` と `getCardsByGachaId(...)` を読んでいる。基本的には `cardCatalog.ts` へ登録すれば、新シリーズはカードガチャに表示される。

## 命名ルール

IDとファイル名は、あとから見ても分かる安定した名前にする。

- ID: `keimarukun-<theme>-card`
- ファイル名: `keimarukun-<theme>-card.png`
- import 変数: `keimarukun<PascalTheme>CardImage`

横向きカードの場合:

- IDやファイル名に `-landscape-card` を含めてもよい。
- カード定義に `orientation: "landscape"` を付ける。

## 画像サイズと文字入れ

同じシリーズのカード画像は、見た目の大きさが揃うように同一寸法で作る。

- 縦向きカードの標準サイズ: `1024x1536`
- 横向きカードの標準サイズ: `1536x1024`
- 生成後は `file` などで寸法を確認する。
- 寸法が揃わない場合は、単純な画像処理で無理に伸縮・クロップするより、プロンプトでサイズ指定を強めて再生成することを優先する。
- カード下部に「けいまるくん」の名前プレートや表記は入れない。カード名は `cardCatalog.ts` の `name` で管理する。

## けいまるくんの基本プロファイル

画像生成プロンプトとカード説明文では、次の特徴を基本にする。

- たん色のふわふわした小さなぬいぐるみ風キャラクター。
- 犬っぽい見た目で、茶色いたれ耳、つんつんした前髪、赤いほっぺが特徴。
- 表情は少しむすっとしているが、かわいく親しみやすい。
- 体型は丸く、手足は短め。子ども向けカードに合うやわらかい雰囲気にする。
- 性格は、ちょっと不器用でがんばり屋。
- 暗い、怖い、リアルすぎる、攻撃的な印象にはしない。

## 好み・苦手なもの

テーマに迷ったら、好きなもの、苦手なもの、よくする行動のどれかをカードの見える要素に入れる。

- 好きなもの: ばなな、白米、あたたかいおふろ、ふわふわの毛布、アヒルのおもちゃ、飛行機のおもちゃ。
- 苦手なもの: 強い風、肉、顔に水がかかること。
- よくする行動: ぷるぷるする、むすっとする、得意げに見せる、ねむそうにする、だいじなものをぎゅっと抱える。
- 表情の候補: むすっと顔、困り顔、得意げな顔、ねむそうな顔、びっくり顔。

## 画像企画チェックリスト

各カードについて次を決める。

- テーマと遊び・行動
- けいまるくんの表情
- 主要な小物
- 背景の場所
- 画像内に入れる上部タイトル
- ファイル名とカードID
- 絵に見えている内容に基づく説明文

シリーズ全体では、できるだけ絵の変化を出す。テーマが許すなら、室内、屋外、食べ物や小物、動きのある場面、静かな場面を混ぜる。

## 画像生成プロンプト例

次の形を出発点にして、カードごとに調整する。

```text
子ども向け学習ゲーム用の、縦向きコレクションカード画像を作成してください。
主人公は、けいまるくん。たん色のふわふわしたぬいぐるみ風の小さな犬キャラクターで、茶色いたれ耳、つんつんした前髪、赤いほっぺ、少しむすっとしたかわいい表情です。
場面: <具体的な場面>
ポーズと行動: <具体的なポーズや行動>
小物: <画面内に見せたい小物>
表情: <基本プロファイルや好み・苦手なものに合う表情>
カードデザイン: カラフルな丸みのあるカード枠、つやのある星ステッカー、上部に日本語タイトル「<タイトル>」。下部に名前プレートや「けいまるくん」の文字は入れない。
画風: 高精細でかわいい、ぬいぐるみ写真とイラストの中間、明るいアーケードカード風、子ども向け、暗いホラー調にしない。
出力: `1024x1536` の縦向き画像。カード全体が見える。切り抜け、透かし、ロゴなし。
```

画像内テキストの品質が悪い場合は、タイトルを短くして再生成するか、画像内テキストを省略して `cardCatalog.ts` の名前と説明で補う。

## ガチャ画面レイアウトの注意

カードガチャの種類ボタンは `GachaPage.tsx` で `CARD_GACHA_DEFINITIONS` を10件ずつページングして描画する。

シリーズ数が増えた場合:

- 3行にせず、ページングを維持する。
- 別ページに `NEW` 対象シリーズがある場合は、ページ送り矢印にも `NEW` を表示する。
- ボタン群が、`left-[55%]` 付近にあるラインナップ表示と被らないか確認する。
- ボタン群の幅を広げた場合は、右端がラインナップ領域に入らないよう `left` を調整する。

カタログ追加だけの作業では、画面全体の大きな redesign はしない。
